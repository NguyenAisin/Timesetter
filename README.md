# Timesetter

**Timesetter Alpha 1.2.1** is a lightweight desktop countdown timer built with Java Swing and Maven.

The project focuses on customizable timers, desktop notifications, and a simple Windows-friendly interface.

## Features

- Countdown timer with days, hours, minutes, seconds, and milliseconds
- Individual increment and decrement controls
- Hold-to-repeat mouse controls
- Left-click to add and right-click to subtract preset durations
- Start, Pause, Stop, and Restart
- Custom notification messages
- Windows system tray notifications and sound alerts
- Repeat and continuous loop modes
- Save and load timer configurations

## Technologies

- Java 25
- Java Swing
- Apache Maven
- NetBeans IDE
- Java Sound API
- Java AWT System Tray

## Getting Started

1. Clone or download the repository.
2. Open the project in NetBeans or another Java IDE with Maven support.
3. Build the project using Maven.
4. Run the `TimeSetter.Timersetter` main class.

Windows builds can be provided separately under GitHub Releases.
